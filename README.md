# MediAI Pro

MediAI Pro is an intelligent disease prediction and clinical decision-support platform. This repository is being built from the approved requirements and architecture in [`docs/`](./docs/README.md).

## Implemented

- React 19 strict TypeScript frontend foundation
- Vite and Tailwind CSS 4
- Shadcn-compatible accessible UI primitives
- Theme and reduced-motion preferences
- Composable routing and protected-route policy
- Public, authentication, and application layouts
- TanStack Query server-state foundation
- Typed Axios/Problem Details API layer
- React Hook Form and Zod form system
- Foundation tests and production build pipeline

Feature pages are intentionally deferred to their approved implementation phase.

## Commands

```powershell
npm.cmd install
npm.cmd run dev
npm.cmd run check
```
